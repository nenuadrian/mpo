# Transformer MD Training

Experiments related to mirror-descent style latent-mixture modeling with transformers.

## Main files

- `train.py`: constructed disentangled transformer + synthetic MTD generator + MD comparison demo.
- `train2.py`: alternative research utilities and estimators.

## Run

```bash
python src/transformer_md/train.py
```
