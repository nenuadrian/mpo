# Transformer Bandits (MPO-Style)

Toy contextual bandit experiment with a Transformer policy and MPO-style updates for a small discrete action space.

## Main entry point

- `train.py`: end-to-end bandit + transformer + MPO-style training loop.

## Run

```bash
python src/transformer_bandits/train.py
```

## Notes

- This script is self-contained and currently uses in-file defaults.
- It is primarily for algorithmic exploration rather than benchmark reporting.
